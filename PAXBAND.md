# Paxband

Paxband is a token. It is not PAXG. It is not Paxos.

## Pair

| | |
|---|---|
| Token | Paxband |
| Quote | USDG |
| Pair | Paxband / USDG |
| Venue | Long |
| Contract | Not set |
| Market | Not open |

Nothing on this sheet can be bought. There is no contract address yet.

## What the pair is

A Paxband / USDG market is a quote. USDG is the other side of the trade. Long is the venue.

## What the pair is not

- Not an ounce of gold.
- Not a PAXG balance.
- Not a Lighter position.
- Not a vault share Long already runs.
- Not a price read from a proof.

Opening the pair does not create any of those.

## When it changes

The contract address and the live Long market go on this sheet together. Until both exist, the market stays not open.
